## 📋 Project Overview

A **Machine Learning** project for **Arabic Sentiment Analysis** (Positive vs Negative) on Twitter (X) data using **N-Gram** technique and **Random Forest** classifier.

This project demonstrates the full pipeline of Arabic text preprocessing and sentiment classification.

---

## ✨ Features

- Full Arabic text preprocessing pipeline
- Handling of Arabic-specific challenges (normalization, digits, punctuation, etc.)
- N-Gram feature extraction (Unigrams + Bigrams)
- Machine Learning model training & evaluation
- Clean and documented Jupyter Notebook

---

## 📊 Dataset

- **Source**: Arabic Sentiment Twitter Corpus
- **Content**: Arabic tweets labeled as Positive (`pos`) or Negative (`neg`)
- **Total Samples**: ~45,000 tweets
- **Language**: Arabic

---

## 🛠 Technologies Used

- **Programming Language**: Python
- **Data Processing**: Pandas, NumPy
- **Text Preprocessing**: NLTK, Regex
- **Feature Extraction**: CountVectorizer (N-Grams)
- **Machine Learning**: Scikit-learn (Random Forest)
- **Visualization**: Matplotlib, Seaborn
